# Code Workflow

For work that spans several specialist roles, or when the user asks for delegation, orchestration, a parallel review or an all-agent workflow, hand it to the `{{name}}` custom agent: pick it with `/agent` or the agent picker, or start Copilot CLI with `copilot --agent {{name}}`. It plans the work, delegates to the installed specialists, requires a durable handoff from each, and reports a verified result.
